Звіт про виконання тестового завдання.

Було виявлено та виправлено наступні недоліки безпеки:
  1. Усі паролі винесено у файл `.env`, який завантажується локально і не потрапляє у відкритий доступ.
  2. Додаток Flask тепер запускається від імені не-привілейованого користувача `appuser`, що обмежує доступ до системи у разі зламу.
  3. Видалено блок `ports` для PostgreSQL. База даних доступна лише всередині мережі Docker через `expose`.
  4. Порт додатка (5000) обмежений лише локальним інтерфейсом (127.0.0.1), що запобігає прямому доступу із зовнішніх мереж без проксі.

Архітектурна схема:
Застосовано принцип мережевої сегментації для ізоляції компонентів:

[Користувач] -> [Firewall (UFW)] -> [Localhost Port 5000] -> 
[Flask App Container] (запуск без root прав)-> [Docker Internal Net] -> 
[PostgreSQL Container] (порти закриті назовні)

Roadmap покращень:
  1. Впровадження SSL-сертифікатів для захисту даних, що передаються між користувачем і сервісом.
  2. Перехід на використання спеціальних програм-сейфів для паролів замість .env файлів.
  3. Впровадження інструментів для щоденної перевірки коду та образів контейнерів на вразливості.
  4. Додавання системи логування для моніторингу активності та виявлення аномалій.
  5. Реалізація фільтра запитів перед сайтом для захисту від підозрілої активності.
